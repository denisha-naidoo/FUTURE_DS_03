# Funnel Analysis Dashboard

## Overview
A Power BI dashboard visualizing a marketing/sales funnel to track conversion rates across each stage of the customer journey.

## Tools Used
- Power BI Desktop
- DAX

## Key Insights
- Drop-off rates at each funnel stage
- Conversion rate optimization opportunities
- Stage-by-stage performance metrics

## How to View
1. Download the `.pbix` file
2. Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
